**¿por qué la lista se declara con val y aún así podemos agregarle elementos?**
Se declara usando val para declarar una lista este se vuelve inmutable y que no se puede sobreescribir la estructura de la variable. 
Se puede agregar elementos ya que el val funcioan como un contenedor, no puede mutar su estructura pero si puede mutar o comdificar su contenido.
