**Titulo:** Creación de un lista de tareas y botones con estados - Con IA

**Estudiante:** Leonardo Favio Ronda Vidalon

**Descripcion:**
Aplicación móvil de lista de tareas desarrollada en Android utilizando Kotlin y Jetpack Compose (Material 3) bajo 
un enfoque declarativo en MainActivity. Implementa gestión de estado reactivo con remember y
 mutableStateListOf para renderizar datos en tiempo real mediante un LazyColumn optimizado con keys únicas. 

**Promt:**
Actúa como diseñador y desarrollador de interfaces y apps moviles, aplicando Kotlin con jetpack compose.

Necesito que crees un fomulario de lista de tareas donde debe haber un campo para ingresar el nombre de las tareas (texto o string), un boton para crear la tarea, debe haber un column abajo del boton donde se muestran las tareas registradas con su respectivo boton de un tacho de basura en cada una para poder eliminar dicha tarea.

Esto está dirigido a estudiantes de TECSUP que registran sus tareas y de esta manera pueden tener una lista de actividades del dia.

Quiero que respondas con el formato y diseño mostardo en la imagen.

Ten en cuenta estas condiciones: usar jetpack compose, no usar java, debes seguir la estructura de la imagen y el diseño, debe ser funcional la app, todo el codigo se va a desarrollar en el MainActivity.
